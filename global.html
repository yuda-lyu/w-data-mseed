(async) WDataMseed(fp, optopt) → {Promise}

Description:

  • 讀取miniSEED檔案，只能用於Windows作業系統

    轉檔由mseed2ascii.exe(與相鄰之cygwin1.dll、cygz.dll)完成，這些外部執行檔不含於npm包，首次轉檔時經ensureBins自GitHub(釘選提交)或環境變數W_BIN_MIRROR之鏡像取得，以bin/manifest.json之SHA-256與大小逐檔校驗後存於快取(預設為套件根之bin-cache/，可由W_BIN_CACHE改位置)，之後自快取取得(亦校驗)；環境變數W_BIN_OFFLINE=1時不連網。取得失敗則reject字串，內含錯誤代碼(如E_OFFLINE_MISSING、E_HASH_MISMATCH)與原因，詳見README〈External executable〉

    轉檔之暫存輸出夾建於作業系統暫存夾os.tmpdir()下(夾名為${fdOutPre}<時間>-<亂數>)，呼叫端之工作路徑內不會出現任何檔。轉檔成功且readWithData=true時刪除該夾；失敗時保留該夾供查找，reject之訊息末行附其絕對路徑(output folder kept for inspection: <路徑>)

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔組mseed2ascii(mseed2ascii.exe與其相鄰之cygwin1.dll、cygz.dll): 首次使用時下載(或自鏡像取得)並以bin/manifest.json之SHA-256與大小逐檔校驗, 整組原子放入快取, 之後自快取取得(亦校驗)

    規格: 外部執行檔之存放下載校驗與離線(制式規格)§6、M6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE(共用快取資料夾)、W_BIN_MIRROR(鏡像, 本地資料夾或http(s)網址)、W_BIN_OFFLINE(1為離線), 見README〈External executable〉

Source:

Example
import WDataMseed from 'w-data-mseed'

//部署前預先取得, 回傳之組資料夾內有mseed2ascii.exe、cygwin1.dll與cygz.dll
let bins = await WDataMseed.ensureBins()
console.log(bins.mseed2ascii)
console.log(bins.bundles.mseed2ascii.files['mseed2ascii.exe'])
