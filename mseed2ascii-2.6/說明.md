
### mseed2ascii 
> https://github.com/iris-edu/mseed2ascii


### 編譯
> 1.使用cygwin編譯mseed2ascii，相關make與gcc安裝詳見cygwin說明

> 2.切換至目錄
````
cd /cygdrive/d/w-data-mseed/mseed2ascii-2.6
````

> 3.執行make，順利則可編譯出mseed2ascii.exe
````
make
````

> 4.複製依賴dll過來exe旁邊(此時仍在本資料夾內，供本機試跑)
````
cygwin1.dll
cygz.dll
````

> 5.產物複製到repo根目錄之`bin/mseed2ascii/`(三個檔須同一資料夾：`mseed2ascii.exe`、`cygwin1.dll`、`cygz.dll`)，並刪除本資料夾內之產物。本資料夾只保留原始碼與文件(GPL-3，供提供原始碼)，不入npm包；執行檔與dll不入npm包，由`bin/manifest.json`校驗後於首次使用時自GitHub或鏡像取得(制式規格：`C:\opensrcOper\dspec\外部執行檔之存放下載校驗與離線.md`，本套件摘要見`sgud/rule/rulebook.md`〈R-BIN〉)

> 6.以`genBinManifest`重產清單(兩步提交：執行檔之提交在前，清單引用它)
````
git add bin
git commit -m "modify: update bin"
git push origin master:master
node toolg/genBinManifest.mjs --commit <上一步提交之40碼雜湊>
npm test
````

### 運行
> 執行檔在repo根目錄之`bin/mseed2ascii/mseed2ascii.exe`(於vs code內使用「./」代表執行檔所在位置，於bat執行直接用mseed2ascii.exe)；套件本身不使用此路徑，而是經`ensureBins()`取得快取內已校驗之同組檔案

> 轉small與large測試檔案指令
````

直接轉出內含數據，多channel則會跑出多檔案
./mseed2ascii.exe _test/small/20200917093752_RST01_acc.mseed

直接轉出內含數據，為GeoCSV格式
./mseed2ascii.exe -G _test/small/20200917093752_RST01_acc.mseed

使用「-o」將強制轉出所有數據至同一個檔案
./mseed2ascii.exe _test/small/20200917093752_RST01_acc.mseed -o 20200917093752_RST01_acc.txt

./mseed2ascii.exe _test/large/SE.RST01.00.HNE.D.2021.001

````
